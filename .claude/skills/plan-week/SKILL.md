Ακολούθησε το `docs/WORKFLOW.md`: ενότητα «`/plan-week`» για τη ροή, ενότητες 1 και 3 για τους κανόνες. Απάντα στα
ελληνικά. Σε αυτό το session **δεν γράφεται κώδικας**.

Πηγές:
- Notion, βάση Blocks (`collection://6f2b0107-6723-4fe4-b05d-a9d242fe884c`): το block με `"Κατάσταση" = 'Τρέχον'`
  (το «Τελειώνει όταν» του είναι ο στόχος) και το επόμενο (`Επόμενο`).
- Notion, βάση Code Tasks: data source `collection://4da2abc0-511d-4dfb-b9c5-180656a8f5e2`, κάρτες με
  Project = Telematica (`https://app.notion.com/p/515a54a507ec4922a7aa1386664028be`) και `Task status` ≠ Done.
  Κολλημένο = In progress / In review με `Started on` πάνω από 7 μέρες πριν (υπολόγισέ το εσύ, το formula δεν
  διαβάζεται με SQL). Δομή, views και άλλες σελίδες δεν αλλάζουν. Δεν υπάρχουν ημερομηνίες ούτε sprint.
- GitHub `CostGal/patra-bus`: ανοιχτά issues (με labels) και ανοιχτά PRs (draft, CI, mergeable).

Ροή:
1. Μάζεψε και διασταύρωσε: issue χωρίς κάρτα, κάρτα με κλειστό issue ή merged PR που δεν είναι Done, διπλά,
   In progress / In review χωρίς κίνηση, PRs που περιμένουν merge, `device-test` issues, αποφάσεις του Kostas.
2. Δείξε σύντομη λίστα ανά ομάδα (ένα στοιχείο ανά γραμμή: TEL-id, #issue, τίτλος, ποιος).
3. Πρότεινε ποιες κάρτες μπαίνουν στο τρέχον Block και με ποια σειρά (3–5 για την επόμενη εβδομάδα), με τον λόγο
   για το καθένα, ξεκινώντας από τα Κολλημένα. Μόνο μία εβδομάδα μπροστά.
4. Όλες οι ερωτήσεις μαζί, αριθμημένες, και σταμάτα.
5. Μετά την απάντηση: ενημέρωσε τις κάρτες (Block, Agent-ready), φτιάξε όσες έλειπαν, και δώσε τη λίστα της εβδομάδας
   με σειρά και την εντολή για το πρώτο task (`/task TEL-<id>`).
